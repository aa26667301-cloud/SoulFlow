# AGENTS.md

## Project Goal
Maintain SoulFlow as a safe, explainable, open-source Mind-Body-Spirit reflection engine.

## Rules
- Traditional Chinese is the primary user-facing language.
- Do not introduce medical diagnosis or treatment claims.
- Do not present spiritual concepts as empirically verified facts.
- Prefer standard library dependencies unless a dependency clearly improves the project.
- Keep recommendation rules deterministic and explainable.
- Add tests for changes to recommendation behavior.
- Preserve user agency: recommendations are options, not commands.

## Contribution Priorities
1. Better reflection prompts
2. More low-risk practices
3. Accessibility
4. Local-first privacy
5. Web/API adapters
