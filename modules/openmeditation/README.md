# OpenMeditation

OpenMeditation 是 SoulFlow 的一般性冥想與覺察工作流模組。

內建練習以低風險、自主停止、自然呼吸為原則，不宣稱治療疾病，也不要求使用者忍耐頭暈、疼痛或不適。

## 功能

- 8 種一般性覺察／冥想練習
- 依主題與時間推薦
- 3–30 分鐘 Session Builder
- 專注、落地、休息、自我友善、轉換等主題
- 無 API Key

## CLI

```bash
python -m soulflow.cli meditations --theme "工作很亂，想專注" --minutes 10
python -m soulflow.cli meditate --theme "準備下班" --minutes 8
```
