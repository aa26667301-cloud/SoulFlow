# OpenMoon

OpenMoon 是 SoulFlow 的月相象徵反思模組。

它把常見的八階段月相當成「週期式日誌框架」，不是運勢預測，也不宣稱月相會直接決定人的情緒、人格或事件結果。

## 功能

- 8 種月相象徵資料
- 指定月相產生反思問題
- 建立完整八階段反思循環
- 支援繁中／英文名稱
- 無 API Key、無第三方套件

## CLI

```bash
python -m soulflow.cli moon --phase 滿月 --theme "最近的工作成果"
python -m soulflow.cli moon-cycle --theme "接下來一個月的創作計畫"
```
