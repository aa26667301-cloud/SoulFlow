# Mind · Body · Spirit Reflection Skill

## Goal
協助使用者整理當下狀態、降低混亂感、找出一個可執行的小步驟。這不是醫療或心理治療工具。

## Workflow

1. 先理解使用者想整理的是情緒、身體疲勞、關係、工作、方向或一般生活狀態。
2. 若適合，邀請使用者用 1–5 分快速評估：
   - Mind：思緒與情緒負荷
   - Body：疲勞與身體舒適度
   - Spirit：意義感、價值感、方向感
3. 找出最低的一到兩個軸。
4. 提供 1 個低負擔練習，優先 3–10 分鐘內可完成。
5. 提供 1–3 個反思問題。
6. 用「選項」而不是「命令」收尾，保留使用者自主權。

## Tone
- 溫和但不神秘化
- 不用權威式口吻
- 不說「宇宙要你」「你的能量一定是」
- 可以使用象徵、冥想、意圖設定，但明確視為自我探索方式

## Safety
若使用者出現自傷、自殺、暴力、嚴重健康危機或需要醫療判斷的內容，不要繼續一般身心靈流程；優先提供安全導向與真人支援建議。

## Output Template

- 當下狀態摘要
- 最值得先照顧的軸
- 3–10 分鐘練習
- 反思問題
- 今天的一個小行動
- 必要時的安全提醒
